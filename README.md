# clubGuide — Campus Club Information Assistant

clubGuide is a campus-specific AI assistant that helps students at **JSSATEB** find information about student clubs. Students ask questions in plain English and get answers based **only** on a curated campus knowledge base, so the assistant doesn't guess or invent details.

The knowledge base currently covers:

- **AWS Student Builders Group**
- **GDG Campus**

## Features

- Natural-language question answering about campus clubs
- Semantic search with sentence embeddings, so questions don't need to match the exact wording of the source text
- Fast similarity search using a FAISS index
- Answers generated by Google Gemini, restricted to the retrieved campus information
- FastAPI backend with a single `/ask` endpoint
- Simple web frontend with suggested questions for quick access

## How It Works

clubGuide uses a Retrieval-Augmented Generation (RAG) approach. The knowledge base is embedded once when the server starts. Each question is then matched against it, and the best match is passed to Gemini as context.

```
        ── On server startup ──
club_info.txt → split into lines (chunks) → embeddings → FAISS index

        ── On every question ──
User question → question embedding → similarity search (top 1)
              → matching line + question sent to Gemini → answer
```

1. **Chunking:** `club_info.txt` is split line by line. Each line is one chunk.
2. **Embedding:** every chunk is converted to a vector with `all-MiniLM-L6-v2`.
3. **Indexing:** the vectors are stored in an in-memory FAISS `IndexFlatL2` index.
4. **Retrieval:** the question is embedded the same way, and the closest chunk is retrieved.
5. **Generation:** Gemini is prompted to answer using only that chunk, and to say the information isn't available if the chunk doesn't contain the answer.

## Getting Started

### Prerequisites

- Python 3.10 or newer
- A Gemini API key from [Google AI Studio](https://aistudio.google.com/app/apikey)

### 1. Clone the repository

```bash
git clone https://github.com/rakshaarr/club-guide-rag.git
cd club-guide-rag
```

### 2. Create and activate a virtual environment

```bash
python -m venv venv
```

Windows:

```bash
venv\Scripts\activate
```

macOS / Linux:

```bash
source venv/bin/activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

The first run also downloads the `all-MiniLM-L6-v2` embedding model, so an internet connection is needed at that point.

### 4. Add your Gemini API key

Create a file named `config.py` in the project root:

```python
API_KEY = "YOUR_GEMINI_API_KEY"
```

Replace `YOUR_GEMINI_API_KEY` with your own key. `config.py` is listed in `.gitignore`. Never commit your API key to GitHub.

### 5. Start the backend

Run this from the project root, because `main.py` reads `club_info.txt` using a relative path:

```bash
python -m uvicorn main:app --reload
```

The API runs at `http://127.0.0.1:8000`. FastAPI's interactive docs are available at `http://127.0.0.1:8000/docs`.

### 6. Start the frontend

Keep the backend running, then serve the `frontend/` folder in one of these ways:

- **VS Code Live Server:** right-click `frontend/index.html` and choose **Open with Live Server**.
- **Python's built-in server:**

  ```bash
  cd frontend
  python -m http.server 5500
  ```

  Then open `http://localhost:5500`.

## Updating the Knowledge Base

All campus information lives in `club_info.txt`. To add or change information:

1. Edit `club_info.txt`.
2. Keep **one fact per line**, since each line is embedded and retrieved as its own chunk.
3. Make every line **self-contained** and name the club in it (for example, "GDG members must maintain 70% attendance." rather than "Members must maintain 70% attendance."). Only one line is retrieved per question, so a line can't rely on its neighbours for context.
4. **Restart the backend.** The knowledge base is embedded at startup, and Uvicorn's `--reload` only watches Python files, so changes to `club_info.txt` are not picked up automatically.

The current knowledge base covers club teams, recruitment, eligibility, attendance requirements, selection processes, events and workshops, club leads, and membership rules.
